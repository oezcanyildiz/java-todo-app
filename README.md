# 📝 Java ToDo App

Eine einfache **Konsolenanwendung in Java**, mit der Aufgaben erstellt, angezeigt, gelöscht und in einer Textdatei gespeichert werden können.  
Perfekt geeignet als Einsteigerprojekt für Java & Git.

---

## 🚀 Funktionen

- ✅ Aufgaben **hinzufügen**
- 📄 Aufgaben **anzeigen**
- ❌ Aufgaben **löschen**
- 💾 Speicherung aller Aufgaben in einer **Textdatei** (`TodoList.txt`)
- 🧾 Einfache Menüführung über Konsole

---

## 🛠️ Technologien

- **Java** 17+
- **Eclipse IDE**
- **Git & GitHub**
- Dateiverarbeitung mit `FileWriter` / `BufferedReader`
